# 「다 그렸어요!」 프로젝트 기획안

> 아이의 그림을 안전하게 보관하고, 그림을 매개로 아이와 보호자의 대화를 돕는 디지털 아틀리에

## 1. 프로젝트 개요

### 1.1 서비스명

**다 그렸어요!**

### 1.2 한 줄 소개

아이들이 자유롭게 그림을 그리고, 원하는 경우 HTP 기반 AI 참고 분석과 그림일기·작품 보관을 경험할 수 있는 아동 중심 창작 서비스입니다.

### 1.3 기획 배경

아이의 그림은 결과물인 동시에 감정과 경험을 표현하는 놀이의 기록입니다. 그러나 보호자는 아이의 그림을 지속적으로 보관하거나, 그림을 계기로 자연스럽게 대화를 시작하기 어렵습니다. 본 서비스는 다음 세 가지 경험을 하나의 흐름으로 연결합니다.

1. **아이**는 부담 없이 그리고 자신의 작품을 완성한다.
2. **보호자와 아이**는 작품과 그림일기를 함께 돌아본다.
3. **보호자**는 AI 분석을 확정적 진단이 아닌 대화의 참고 자료로 활용한다.

## 2. 목표와 원칙

### 2.1 사업·제품 목표

- 아동이 3분 안에 그림 그리기를 시작할 수 있는 낮은 진입장벽 제공
- 그림, 그림일기, 분석 기록을 한 곳에 축적하는 개인 아틀리에 구축
- AI 분석 결과를 통해 보호자와 아이 사이의 대화 소재 제공
- 작품 저장과 공유 과정에서 아동의 개인정보와 그림 데이터를 안전하게 보호

### 2.2 핵심 원칙

- **아동 우선:** 복잡한 설정과 전문 용어를 줄이고, 큰 버튼과 친근한 문구를 사용한다.
- **놀이 우선:** 분석을 강요하지 않고 자유 스케치와 심리 분석 모드를 분리한다.
- **참고용 해석:** 결과를 의료적·임상적 진단으로 표현하지 않으며, 관찰 및 대화의 참고 자료임을 명확히 한다.
- **보호자 통제:** 로그인, 저장, 이메일 발송은 보호자가 이해하고 선택할 수 있게 한다.
- **기록의 연속성:** 한 번의 분석보다 시간에 따른 작품과 감정의 변화를 볼 수 있게 한다.

## 3. 대상 사용자

### 3.1 주요 사용자

| 사용자 | 니즈 | 서비스에서의 역할 |
|---|---|---|
| 아동(주 사용자) | 재미있고 쉽게 그림을 그리고 인정받고 싶음 | 그림 그리기, 대상 선택, 그림일기 작성 |
| 보호자(관리·열람 사용자) | 아이의 작품을 보관하고 대화를 시작하고 싶음 | 로그인, 기록 확인, 분석 결과 열람·공유 |

### 3.2 사용 상황

- 가정에서 아이와 보호자가 함께 작품을 만드는 시간
- 어린이집·학교·미술 활동 후 작품을 디지털로 남기는 상황
- 보호자가 아이의 최근 관심사와 감정 표현을 자연스럽게 물어보고 싶은 상황

## 4. 핵심 사용자 여정

### 4.1 자유 창작 여정

1. 홈 화면에서 **자유롭게 그리기** 선택
2. 캔버스에서 색상·붓 크기·지우기·실행 취소·다시 실행을 사용
3. 완성 후 작품을 다운로드하거나 갤러리에 저장
4. 로그인한 경우 개인 아틀리에의 작품 갤러리에 보관

### 4.2 그림 심리 참고 분석 여정

1. 홈 화면에서 **마음 담아 그리기/분석** 선택
2. 사람·나무·집 중 실제로 그릴 대상을 선택
3. 캔버스에서 그림을 완성
4. 캔버스 면적, 중심 위치, 선의 속도 등 실시간 규칙 기반 지표 산출
5. 서버의 Gemini 비전 모델을 통한 HTP 참고 리포트 생성
6. 분석 결과 확인 및 소견서 인쇄·저장
7. 필요 시 보호자 이메일로 리포트 발송
8. 작품과 분석 기록을 개인 아틀리에에 보관

### 4.3 그림일기 여정

1. 아틀리에의 **일기장**에서 작품 선택
2. 오늘의 경험이나 기분을 텍스트로 작성
3. 날짜·날씨와 함께 그림일기 저장
4. 누적된 일기를 다시 열어 작품과 당시의 생각을 회고

## 5. 기능 기획

### 5.1 홈 및 탐색

- 서비스 소개와 캐릭터 중심의 친근한 첫 화면
- 자유 스케치와 분석 모드의 명확한 분리
- 로그인 상태, 닉네임, 프로필 이미지 표시
- 작업 중인 화면에서 홈으로 이동할 때 저장 여부 확인

### 5.2 디지털 캔버스

- 색상 팔레트 및 색상 휠
- 붓 크기 조절
- 실행 취소·다시 실행
- 캔버스 초기화 및 전체 화면
- 작업 중 임시 저장/복구 안내
- 작품 이미지 다운로드 및 인쇄
- 분석 모드에서 사람·나무·집 대상 선택

### 5.3 작품 갤러리

- 작품 썸네일, 작성일, 모드(자유/HTP 분석) 표시
- 작품 상세 보기
- 작품 삭제 및 삭제 확인
- 작품을 기반으로 그림일기 작성
- 로그인 계정별 서버 저장과 로컬 캐시 동기화

### 5.4 그림일기장

- 작품을 첨부한 일기 작성
- 텍스트, 날짜, 날씨 기록
- 일기 상세 보기와 삭제
- 삭제 시 원본 작품과 심리 분석 기록은 유지

### 5.5 심리 기록

- 분석 이미지와 분석 리포트 보관
- 리포트 상세 보기
- 소견서 인쇄·저장
- 보호자 이메일 발송 상태와 수신 주소 표시
- “전문가의 진단을 대체하지 않는 참고용 결과” 고지

### 5.6 계정 및 데이터

- Google·Kakao 기반 로그인과 이메일형 로그인 흐름
- 닉네임 및 프로필 이미지 수정
- 로그아웃
- 사용자별 작품·일기·분석 기록 분리 저장
- 브라우저 로컬 저장소와 SQLite 서버 저장소 간 데이터 병합

## 6. AI 분석 정책

### 6.1 분석 입력

- 완성된 그림 이미지
- 캔버스 면적 활용도(`areaRatio`)
- 그림 중심의 세로 위치(`centerYRatio`)
- 선의 속도(`speed`)
- 사용자가 선택한 실제 그림 대상

### 6.2 결과 원칙

- 분석 결과는 아이의 상태를 단정하지 않고 “~을 시사할 수 있습니다”와 같은 관찰형 문장으로 제공한다.
- 그림에 없는 대상에 대한 해석을 생성하지 않는다.
- 보호자가 아이에게 결과를 낙인처럼 전달하지 않도록 대화 질문을 함께 제공한다.
- 모델 오류·시간 초과·분석 불가 시 원인을 안내하고 재시도 경로를 제공한다.
- 결과 화면과 이메일에 참고용·비진단성 고지를 반복 노출한다.

### 6.3 권장 결과 구성

1. 이번 그림에서 관찰된 특징
2. 가능한 정서·표현 경향
3. 아이에게 물어볼 수 있는 열린 질문
4. 보호자가 지켜볼 생활 맥락
5. 전문 상담이 필요한 경우의 안내

## 9. 출시 단계

### Phase 1. MVP 안정화

- 자유 그리기, 분석 그리기, 작품 저장, 기본 아틀리에 흐름 안정화
- 모바일·태블릿 캔버스 사용성 개선
- 로그인 실패 및 저장 실패에 대한 명확한 오류 처리

- 보호자용 대시보드와 최근 기록 요약

- 작품·일기·분석 기록의 내보내기
- 가족 공유 링크 또는 제한적 공유 기능

### Phase 3. 성장 기능

- 주간 창작 미션과 연령별 프롬프트
- 감정 스티커·기분 기록
- 시간순 작품 변화 보기
- 보호자용 대화 질문 추천
- 미술 교사·상담 전문가를 위한 별도 열람 권한(선택)

## 10. 화면 구조

1. **홈**: 서비스 소개, 자유 스케치, 분석 모드 진입
2. **모드 선택**: 자유 그리기와 HTP 분석 안내
3. **그리기 화면**: 캔버스, 도구, 대상 선택, 저장/완료
4. **분석 결과**: 진행 상태, 리포트, 인쇄·이메일 발송
5. **나만의 아틀리에**: 작품, 일기장, 심리 기록, 프로필 탭
6. **상세 모달**: 작품·일기·분석 기록 상세 및 삭제 확인
7. **로그인/프로필**: 로그인, 닉네임 수정, 로그아웃

## 12. 최종 제품 정의

이 서비스의 핵심 가치는 “그림을 분석해 아이를 판정하는 것”이 아니라, **아이의 창작 과정을 존중하면서 작품을 오래 보관하고 보호자와의 대화를 돕는 것**입니다. 따라서 분석 기능은 독립적인 진단 상품이 아니라 자유 창작과 기록 경험을 풍부하게 하는 보조 기능으로 운영합니다.

출시 우선순위는 다음과 같습니다.

1. 작품이 안전하게 저장되고 다시 열리는 경험
2. 아이가 쉽고 즐겁게 그림을 완성하는 경험
3. 보호자가 오해 없이 결과를 이해하는 경험
4. 시간이 지날수록 작품과 대화가 쌓이는 경험
